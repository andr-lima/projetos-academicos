# 🚀 Projetos Acadêmicos

Repositório para projetos acadêmicos desenvolvidos ao longo da faculdade.

## Estrutura

Cada projeto terá sua própria pasta com README explicando o objetivo, instruções de compilação e uso.

```
projetos-academicos/
├── projeto-01/
│   ├── README.md
│   └── ...
└── projeto-02/
    ├── README.md
    └── ...
```

## 🛠️ Tecnologias

- **C** (principal linguagem do semestre)
- Outras conforme necessidade dos projetos
